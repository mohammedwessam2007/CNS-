# Personal Objective Profile

This is a private study system optimized for one learner.

## Primary outcome
Reliable strong performance in Kasr Al Ainy medicine while maximizing **understanding and marks per occupied cognitive minute**.

## Lifestyle objective
Medicine should not unnecessarily consume the day.
A roughly **1.5 to 2 focused hour/day** envelope is desirable when the evidence says it is sufficient, but it is not a hard quota and must never cause unsafe omission of required learning.

Unused study minutes are valuable because they return to the learner's wider life and projects.

## Experience preferences
- iPad-first
- highly visual
- professor spoon-feeds the conceptual sequence
- minimal resource hunting
- minimal setup / settings
- one obvious `Resume learning` action
- no giant dashboards
- no repetitive visual wallpaper
- no AI-looking anatomy filler
- no memorizing source options as a substitute for understanding
- small Egyptian-Arabic reasoning commands can be used when they improve recall
- medical terminology should remain exam-correct English / standard terminology

## Teaching law
Fresh content:
`visualize → understand → mentally simulate → predict → test → visual repair`

Mature content:
`test → prove → repair only where needed → stop`

## Personalization law
Adapt from observed evidence, not personality stereotypes:
- correctness
- confidence
- latency
- forgetting
- transfer
- modality exposure
- resource exposure
- visual exposure
- time of day
- fatigue
- error family
- actual exam results

## Success criterion
The learner should feel that the system has done the planning, curation and sequencing for him.
He should mainly have to **look, understand, answer, and leave**.
