# Architecture Law

## Stable layers
- Backbone: monolithic course engine / source bank / scheduling / base renderers.
- v9: real topic visual sources.
- v10: contextual visuals and embedded teaching-video UX.
- v11: low-friction course shell.
- v12: optimizer / mastery / error / ROI / digital twin.
- v13: long-horizon Learning Twin.
- v14: understanding-first Qbank + calendar + visual genome + Egyptian micro-commands + visual autopsy.

## Modification rule
Prefer wrapping/extending stable functions rather than duplicating state machines.
No second competing calendar engine.
No second mastery model.
No second render loop unless strictly necessary.

## UX law
Normal learner flow remains:
`Resume learning`

Advanced intelligence is silent.
The learner should not configure:
- which resource
- which topic
- how many questions
- whether to review
- how deep to explain
unless a genuine ambiguity requires it.

## State law
All new v14 state is namespaced.
Must tolerate missing v14 state and migrate existing users without destructive reset.
Never erase existing v9-v13 evidence.

## Assessment law
Practice may teach.
Held-out mock must assess first.
