# Visual Curation Doctrine

## Goal
Every teaching paragraph and every **practice** MCQ should earn a visual that helps the learner build the actual concept. The system must never confuse "has an image" with "teaches visually."

## Source hierarchy
1. Actual source-bank figure belonging to the question.
2. Manually curated open-license anatomy/histology/physiology visual.
3. Real human specimen, plastinate, cadaver, micrograph or clinical image from a reputable educational source.
4. Established pathway/mechanism diagram with clear provenance.
5. Official teaching-video embed/thumbnail and routed timestamp.
6. Reputable academic atlas link.
7. If none exists: show a no-visual state rather than inventing misleading anatomy.

## Strong academic donors
- University of Michigan Medical School SecondLook / Michigan Histology / Neuroanatomy: excellent specimen, histology and neuroanatomy review donors.
- Stanford Medicine's image/media resource map is useful for finding public-domain and Creative-Commons biomedical repositories.
- Wikimedia Commons is acceptable only with relevance scoring, provenance and license metadata.
- Existing course video donors include Ninja Nerd, Dr Matt & Dr Mike, Sam Webster, AnatomyZone, Kenhub, 2-Minute Neuroscience and Armando Hasudungan.

## Copyright law
Do not bulk-download or republish arbitrary copyrighted YouTube frames.
Use official embeds/thumbnails/timestamps, licensed/open assets, or user-supplied screenshots with permission.

## Anti-repeat law
A repeated image is acceptable only when it is the canonical visual and repetition is deliberate.
Otherwise apply:
- same-session penalty
- same-day penalty
- adjacent-question penalty
- recent-asset penalty
- same-modality penalty
- concept-angle diversity

For a repeated concept, rotate:
labeled diagram → real specimen/cadaver → teacher visual → unlabeled recall → look-alike comparison.

## Question-specificity test
Before accepting a visual ask:
1. What exact reasoning move does this question require?
2. Does this image display that structure/mechanism/discriminator?
3. Could the same image be pasted beside ten unrelated questions? If yes, reject.
4. Does it accidentally hint at the answer before a held-out mock? If yes, reject pre-answer use.
