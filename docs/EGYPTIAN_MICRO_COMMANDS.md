# Egyptian Arabic Micro-Command Dictionary

These are **cognitive commands**, not decorative translations. Use one only when it matches the reasoning move.

## Universal
- **كوّن الصورة** — build the picture before wording.
- **رجّعها من دماغك** — reconstruct it closed-book.
- **اقفل عالجوهر** — ignore option noise, lock onto the core concept.
- **توقّع قبل الاختيارات** — predict before choices appear.

## Look-alikes / histology / identification
- **طلّع شبيهه برّه** — eliminate the nearest look-alike.
- **امسك الفرق** — identify one decisive discriminator.
- **دَوّر عالعلامة الفاصلة** — find the giveaway feature.
- **حطّهم جنب بعض** — compare correct vs distractor side-by-side.
- **فرّق النسيج** — discriminate tissue architecture.

## Anatomy / relations
- **ظبّط الاتجاه** — orient first.
- **شوف علاقته بإيه** — map relations.
- **شوف معدّي منين** — identify the route / passage.
- **مين معصّبه؟** — identify innervation.
- **مين بيغذّيه؟** — identify blood supply.

## Tracts / pathways
- **امشي المسار** — trace start → synapse → crossing → destination.
- **فين بيكروس؟** — locate the decussation.
- **شوف رايح فين** — identify destination.

## Lesion / clinical
- **حدّد الإصابة** — localize lesion first.
- **هيبوّظ إيه؟** — predict deficit from damaged structure.
- **يمين ولا شمال؟** — force laterality.

## Physiology
- **شغّل الميكانيزم** — run input → mechanism → output.
- **مين بدأ؟** — identify initiating variable.
- **مين رد؟** — identify response / feedback.
- **لو دا اتغيّر، الباقي يعمل إيه؟** — perturb one variable and predict the chain.

### Language law
The app may use Egyptian Arabic for the tiny command/cue. Core medical terminology remains accurate English/standard terminology so the student can answer the exam correctly.
