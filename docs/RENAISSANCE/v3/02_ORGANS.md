## 4. Language as a civilisation portal (§34) — open

Moved from the frontier to open, controllable work on review in v18.1: §34 is a rule for how language is learned, and a
first language experience can be built now, so calling it frontier would have hidden it from the ledger. No language
organ is built yet. When one is, it follows §34: language unlocks literature, humour, film and idiom, not
vocabulary lists. The first candidate is classical Arabic through poetry he already half-knows by ear (the maqam
session gives the entry), then Russian through the Karamazov passages he now possesses in English.

## 5. At scale (§235) — the perpetual frontier

The machinery for scale exists and is tested: the civilisation graph, the masterpiece compiler, the possession
ladder, the compiler that picks unpossessed works. What does not exist yet is volume: thousands of works, every form
(drama, epic, essay, memoir, satire, myth, religious text), every medium (painting and sculpture need lawful images;
recorded performance needs licensed audio). §169 says there is no terminal syllabus, so this requirement is never
counted as closed; the next works queued for the compiler, one per form: *Hamlet* (drama), the *Odyssey* in a
public-domain translation (epic), Montaigne's "Of Cannibals" (essay), Ibn Battuta's travels (memoir), *Candide*
(satire), the *Epic of Gilgamesh* (myth), and the Qur'anic story of Joseph with its commentaries (religious text,
treated with the seriousness §25 asks for).
