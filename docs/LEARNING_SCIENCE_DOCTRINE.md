# Learning Science Doctrine

INTELLECTUALITY is not optimized for maximum content exposure. It is optimized for durable, transferable learning per occupied minute.

## Core principles
- **Retrieval practice:** require generation before recognition when feasible.
- **Spacing:** revisit after forgetting risk grows, not because a calendar says "review everything."
- **Interleaving:** mix confusable concepts when discrimination is the skill.
- **Worked examples then fading:** teach a complete causal/spatial model first, then progressively remove support.
- **Dual coding:** combine verbal structure with a visual that actually represents the same concept.
- **Cognitive-load control:** one clear model beats five competing explanations.
- **Error-driven learning:** a wrong answer is a misconception diagnosis event, not a red X.
- **Confidence calibration:** confident-wrong errors deserve heavier repair than unsure misses.
- **Transfer:** changed questions and different modalities must prove the model generalizes.
- **Desirable difficulty with guardrails:** make retrieval effortful enough to learn, not so opaque that the learner guesses.
- **Stop rules:** once marginal learning gain is low, return time to the learner.

## Fresh-concept law
Do not pretest with answer-revealing options when the learner has no usable model.
For fresh content:
`visual model → explanation → prediction → source MCQ`.

## Mature-concept law
When strong evidence exists:
- shorten explanation
- test first
- repair only where evidence fails

## Visual law
A visual is not useful because it is pretty.
It is useful if it helps the learner:
- orient
- discriminate
- trace
- predict
- localize
- reconstruct

## Outcome law
The Learning Twin should update from real outcomes, but avoid overfitting to tiny samples.
Personalization must be evidence-weighted and reversible.
