# 3. Problem statement

The current system has four important trust/learning defects.

## Defect A — repeated visuals
A few relevant images are reused so often that they become wallpaper.
A visual being "related to CNS" is not enough.

## Defect B — MCQ-first contamination
Parts of the flow can make a new learner infer the source item from option exposure rather than construct the concept.

Questions must prove understanding after teaching. They are not the primary teaching language for a fresh concept.

## Defect C — wrong-answer correction is not visual enough
The learner must understand:
- what the correct concept looks like
- what their chosen distractor corresponds to
- why those two are different
- which single discriminator would have saved the question
- how to recall it next time without options

## Defect D — stale calendar
The app can appear to be "on Sep 21" even when the actual local date is Sep 22.
The app may preserve unfinished Sep-21 work, but it must never lie about the date.

# 5. Question primer

Every eligible **practice** MCQ should receive a compact teaching primer before options.

Required structure:

### UNDERSTAND FIRST · OPTIONS LOCKED

### 1. كوّن الصورة / SEE IT
Show the best available question-specific visual.

### 2. UNDERSTAND IT
Teach the relationship/mechanism needed to derive the answer.
Do not reproduce the answer sentence.
Do not bold the answer term before the question.
Do not leak the exact option wording.

### 3. BUILD THE MOVIE
Anatomy:
orientation → relations → route/supply/innervation → lesion

Physiology:
input → receptor/sensor → mechanism → output → feedback → perturbation

Histology:
silhouette → architecture → 3 discriminators → closest look-alike → function

### 4. EXAM CONVERSION
Tell the learner how this concept gets converted into an exam move.

### Prediction
Ask them to predict in their own words.

### Gate button
`I CAN PICTURE IT → ASK ME THE MCQ`

Only then render the exact source question.

The source stem/options/key must remain byte-for-byte semantically intact.

# 8. Anti-repeat engine

Current "used count" is not enough.

Implement a bounded recent-history model.

Penalties:
- exact same image in previous question: enormous
- exact same image in previous 5 questions: strong
- exact same image same session: strong
- exact same image same day: moderate
- same modality 3+ times consecutively: moderate
- image used repeatedly across unrelated concepts: strong

Exceptions:
- exact source figure for that item
- canonical anatomy plate where no legitimate alternative exists

Rotation goal for repeated concepts:
1. labeled schematic
2. real specimen
3. cross-section / different orientation
4. teacher/video visual
5. unlabeled recall
6. look-alike pair

# 9. Wrong-answer Visual Autopsy

This is mandatory for every wrong practice source MCQ.

Header:
**ليه إجابتك غلط بصريًا؟**

Required elements:

## Correct side — اللقطة الصح
Show the correct visual anchor.

## Chosen distractor side — إنت خدت شبيهها / البديل الغلط
Map the learner's selected option to a trustworthy distinct visual **only if semantically valid**.

Never display a random visually similar image for a distractor merely because search returned something.

If the distractor is conceptual and has no meaningful single image:
say:
`No trustworthy distinct visual exists for this distractor. Use the decisive reasoning difference below.`

## Side-by-side comparison
Correct vs chosen.

## الفرق الفاصل
One decisive discriminator.
It must be about the actual distinction in this item.

Examples:
- dorsal root contains sensory afferents; ventral root is motor
- corticospinal crossing location
- sensory vs autonomic ganglion satellite-cell arrangement
- posterior vs anterior spinal artery territory
- ionotropic vs metabotropic time/mechanism
- cranial nerve branch relation
- ipsilateral vs contralateral deficit

## Egyptian command
Select one contextual cognitive command.

## No-options reconstruction
Before allowing repair/retest:
ask learner to say or type the answer logic without choices.

Do not require long prose.
One compact reconstruction is enough.

## Repair
Then route into existing repair.
Do not bypass v12 error evidence or v13 teaching-memory learning.

3. What would the nearest look-alike be?
4. Is the image medically correct and human-relevant?
5. Is it legible on an iPad without pinch-zoom?
6. Is its provenance and permitted use known?
7. Is it better than the current canonical visual?
8. Is it being repeated because it is truly canonical or merely because the search engine is lazy?

## Anatomy
Ideal visual stack when available:
- clean orientation diagram
- real cadaver / plastinate / specimen
- unlabeled recall version
- sectional/radiologic view when clinically useful
- lesion consequence / relation overlay

## Histology
Ideal visual stack:
- real low-power micrograph
- zoomed discriminator
- nearest look-alike side by side
- unlabeled recognition view

## Physiology
Ideal visual stack:
- mechanism diagram
- causal animation / state transition
- graph if the concept is quantitative
- perturbation view showing what changes when one variable is altered

Do not use decorative gross-anatomy images to "visualize" a physiology mechanism.

## Animation law
The user wants images / GIF-like learning where it improves understanding.
When a static image cannot express direction or time, prefer:
- licensed/open animation
- interactive step-through
- original simple vector/canvas mechanism animation built from verified facts
- sequential still frames

Do not generate photorealistic anatomy with an image model as a substitute for real anatomy.
Original schematic arrows/animations are acceptable only when medically validated and clearly schematic.

# 35. Every wrong answer must become a visual misconception repair

For every practice MCQ missed, classify **why the chosen option felt plausible**.

The repair should answer:
- what the learner pictured
- what the correct concept actually is
- where those models diverge
- the one discriminator that would have saved the question
- how to reconstruct the concept without options

If a chosen distractor represents a visually distinct structure/tissue/pathway:
show it side by side with the correct visual.

If the distractor is abstract and cannot be honestly represented by an image:
use a causal diagram or textual contrast rather than a fake image.

The command should be contextual Egyptian Arabic, for example:
- `طلّع شبيهه برّه`
- `امسك الفرق`
- `امشي المسار`
- `حدّد الإصابة`
- `شغّل الميكانيزم`

The Arabic cue is a **memory-control instruction**, not a translation layer. Medical terminology remains exam-appropriate.
